#  BiblioManager

Application de gestion de bibliothèque développée en **Java 25** dans le cadre de mon apprentissage du développement backend à l'ISEP Diamniadio.

## Présentation

BiblioManager est un projet fil rouge dont l'objectif est de concevoir progressivement une application permettant de gérer les livres, les exemplaires, les adhérents et les emprunts d'une bibliothèque.

Le projet commence par une application console. Il évoluera progressivement vers une application backend connectée à une base de données.

## Technologies

- Java 25
- Git et GitHub
- VS Code
- PostgreSQL et JDBC (étapes futures)
- Spring Boot (évolution envisagée)

## Fonctionnalités prévues

- Gestion des livres et des auteurs.
- Gestion des éditions et des exemplaires.
- Gestion des adhérents.
- Gestion des emprunts et des retours.
- Consultation de l'historique des emprunts.


## Objectif pédagogique

Mettre en pratique les notions de Java à travers un projet concret, en privilégiant la compréhension, la conception et l'autonomie dans le développement.
